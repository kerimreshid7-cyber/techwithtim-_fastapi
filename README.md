# 📸 Photo & Video Sharing Platform

**A media-sharing web application built with Python and FastAPI.**

This project is a backend-focused web application for sharing photos and videos. Users can create accounts, authenticate, upload media, and access posts shared on the platform.

I'm building this project while learning FastAPI through the practical tutorial by **Tech With Tim**.

## 🚀 Project Overview

The application provides a simple platform where authenticated users can:

- Create and share photo posts.
- Upload and share video posts.
- View posts shared by other users.
- Retrieve individual posts.
- Manage their own posts.
- Register and log in to their accounts.
- Access protected API endpoints.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **FastAPI** – Backend API framework.
- **Uvicorn** – ASGI server.
- **SQLAlchemy** – Database interaction.
- **Pydantic** – Data validation and serialization.
- **SQLite** – Database.
- **ImageKit** – Image and video upload and storage.
- **JWT** – User authentication and authorization.
- **Streamlit** – Frontend interface.

## ▶️ Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd photo_video_sharing
```

Activate the virtual environment:

```bash
source .venv/bin/activate
```

Run the application:

```bash
fastapi dev main.py
```

Open the interactive API documentation:

http://127.0.0.1:8000/docs
